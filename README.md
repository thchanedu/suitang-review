# 隋唐治世 · 複習教材（中五中史 · 甲部單元四）

本倉庫收錄中五中國歷史「隋唐治世」單元的複習資源，含互動遊戲、腦圖與可列印筆記。

## 內容一覽

| 檔案 | 說明 |
| --- | --- |
| `index.html` | 措施配對遊戲（瀏覽器直接開啟，電腦／iPad 適用） |
| `mindmap.html` | 三帝腦圖：隋文帝／唐太宗／唐玄宗放射式導圖 |
| `answers/suitang_game_answer.docx` / `.pdf` | 遊戲答案：36 條專屬措施 + 6 條共同措施 |
| `review/suitang_total_review.docx` / `.pdf` | 總複習筆記：三帝整體正面評價 + 考問重點及出題趨勢分析 |

## 遊戲玩法

遊戲分兩個模式：

1. **① 專屬措施**（36 條）：點選措施卡，再點選對應的皇帝（隋文帝／唐太宗／唐玄宗）。可按「政治／經濟／軍事／文教」範疇篩選。
2. **② 共同措施**（6 條）：三省六部制、州縣二級制、均田制、租庸調制、府兵制、科舉制 —— 分兩段作答：「誰創立／推行」→「誰改良／完善」，答對顯示區分線索。

## 腦圖

`mindmap.html` 為三位皇帝（開皇／貞觀／開元之治）的放射式腦圖，皇帝為中心、六範疇開枝（政治／經濟／軍事／文教律法／晚年失政／正面評價）。

## 使用方式

- **本機開啟**：雙擊 HTML 檔即可使用（無需上網）；筆記可直接開啟 .docx 或 .pdf。
- **部署到 GitHub Pages**：上傳本倉庫後，Settings → Pages → Source 選 main 分支，即可用網址線上分享給學生。
